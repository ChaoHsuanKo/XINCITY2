# 🏍️ 鑫悅社區機車車位抽籤系統 (XINCITY2)

這是一個專為社區大樓設計的高質感、無伺服器依賴（純前端）機車車位抽籤與查詢系統。本專案以 **深色奢華（Premium Dark）** 及毛玻璃效果為視覺核心，搭配自研的無版權 Web Audio API 音效合成引擎與響應式 RWD 佈局，不論在桌機還是手機上，都能展現極致流暢與現代感的操作體驗。

---

## 🌟 主要功能與特色

### 1. 🔄 單步抽籤模式 (`index.html`)
一戶接續一個車位的精緻抽籤流程，極具現場儀式感：
*   **第一階段：抽出住戶** ➜ **第二階段：分配車位** 雙步驟獨立抽選。
*   支援亂數滾動動畫與風格音效。
*   自動儲存與載入本機抽籤進度，不怕瀏覽器意外關閉。

### 2. ⚡ 批次抽籤模式 (`batch.html`)
一鍵自動化處理大批次抽選，省時省力：
*   **洗牌產生順序**：一鍵生成所有住戶的隨機中籤順序，並於右側表格排列。
*   **自動逐一分配**：可自訂分配間隔時間（秒），系統將自動以動畫向下逐個分配車位。
*   **動態變更秒數**：在自動抽選進行中，**可隨時修改間隔秒數**，立即生效，不需暫停。
*   **暫停與繼續**：支援中途隨時暫停與接續分配，方便調整。

### 3. 🔍 車位結果查詢系統 (`search.html`)
為住戶與管理者打造的快速檢索頁面：
*   **本機自動載入**：會自動偵測並載入上一次抽籤的本機快照。
*   **拖曳 CSV 匯入**：可將歷史匯出的結果 CSV 檔案直接拖入網頁中載入資料。
*   **門牌模糊搜尋**：除了搜尋戶號外，直接輸入「426號」、「15樓」、「之5」等地址關鍵字也能快速過濾出中籤結果。
*   **精準結果高亮**：精確匹配的戶號會以綠色發光霓虹框卡片大字高亮呈現。

### 4. 📂 Excel / CSV 數據匯出 (支援中途匯出)
*   可在抽籤結束或**中途暫停**時，一鍵匯出已產生的結果。
*   CSV 格式內建 **UTF-8 BOM (`\ufeff`)**，Microsoft Excel 直接雙擊開啟**保證繁體中文顯示完美、絕不亂碼**。

### 5. 🔊 純代碼合成音效與風格切換
採用 Web Audio API 即時物理合成，不需載入任何外部音效檔，開啟速度極快且完全無版權問題。內建三種風格：
*   `🎮 8-bit 遊戲風`：復古紅白機雙音符與金幣聲。
*   `✨ 科技現代風`：水晶般純淨的正弦波大調和弦。
*   `🥁 經典懸疑風`：指針滴答懸疑感搭配英雄銅管開場樂。

### 6. 🚫 特殊車位排除與設定同步
*   在設定彈窗中，可輸入要排除的車位（支援逗號與區間，如 `5, 12, 100-105`）。
*   設定與秒數、音效風格皆使用 `localStorage` 自動跨分頁同步。

## 🏠 門牌地址自動轉換定義

系統將內建戶別代碼自動解析並於下方呈現為實際門牌備註，例如 **`A8-15F`** 會自動呈現為 **`426號15樓之5`**。

### 對應關係表：
*   **店面 (S1, S2, S3, S5)**: `1樓店面 S1 / S2 / S3 / S5`（共 4 戶）
*   **A1** : `426號之1`
*   **A2** : `428號之1`
*   **A3** : `428號之2`
*   **A5** : `428號之3`
*   **A6** : `428號之5`
*   **A7** : `428號之6`
*   **A8** : `426號之5`
*   **A9** : `426號之3`
*   **A11**: `426號之2`

> 💡 **名額說明**：住戶共 198 戶（2F-23F，A1-A11 每層 9 戶）加上 4 間店面（S1, S2, S3, S5），合計共 202 戶參與抽籤。

## 🚀 快速開始使用

本專案為 **純靜態網頁架構**，不需安裝任何 server，亦不需下載任何 Node.js 依賴套件。

1.  **下載本專案代碼**（或使用 `git clone`）。
2.  在專案根目錄下，直接雙擊滑鼠開啟網頁：
    *   開啟 [index.html](index.html) 開始進行單步抽籤。
    *   開啟 [batch.html](batch.html) 進行批次自動抽籤。
    *   開啟 [search.html](search.html) 供住戶或管理員查詢結果。
